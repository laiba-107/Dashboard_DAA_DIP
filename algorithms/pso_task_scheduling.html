Particle Swarm Optimization — Task Scheduling

Assign N independent tasks to M machines so that the makespan (maximum completion time over all machines) is minimized. Each particle in PSO encodes a complete assignment of tasks to machines.

Problem & Algorithm Overview
Metaheuristic · PSO
Optimization Problem

We have N tasks, each with a processing time \( p_i \), and M identical machines. An assignment chooses a machine index \( m_i \in \{0,\dots,M-1\} \) for every task \( i \).

The load of machine \( k \) is \( L_k = \sum_{i : m_i = k} p_i \). The makespan is \( C_{\max} = \max_k L_k \). Our goal is to minimize \( C_{\max} \).

Particle Swarm Optimization (PSO)
  • Each particle has a position vector x = [x₁,…,xₙ] in continuous space. We map it to a discrete assignment by machine = floor(xᵢ).
  • Velocity v is updated using:
    v = w·v + c1·r1·(pBest − x) + c2·r2·(gBest − x)
  • Position is updated as x = x + v and clamped to the range [0, M−ε].
  • Fitness of a particle = makespan of its assignment. PSO iteratively improves particles toward lower makespan.
