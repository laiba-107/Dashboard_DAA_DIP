Theory: Binary vs Multi-Class Classification
  • This block = feature extractor. It doesn’t decide the class yet; it creates feature maps.
  • Binary classification: last dense layer has 1 neuron with sigmoid activation.
  • Output = probability of “class 1” (e.g., cat vs not-cat). Threshold (like 0.5) decides 0/1.
  • Multi-class classification: last dense layer has K neurons (K = number of classes) with softmax activation.
  • Output = probability distribution over all classes (sum of outputs = 1).
  • You can explain in your CNN theory tab: “Conv+Pooling → flatten → Dense → (Sigmoid / Softmax)”.
