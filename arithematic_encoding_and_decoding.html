Core Idea

Arithmetic coding represents an entire message as a single fractional number in [0, 1), by repeatedly subdividing the interval using a probability model.

  • Build a symbol–probability model and initial sub-intervals in [0,1).
  • For each symbol, update the interval using D (current range width) and cumulative probabilities.
  • Any value in the final interval (e.g. the tag) encodes the whole message.
  • Decoding reverses this: repeatedly locate the tag in the sub-intervals to recover each symbol.

Key Formulas

D = Upper₍current₎ − Lower₍current₎
D is the width of the current interval.
NewLower(symbol) = Lower + D × CDFbefore(symbol)
NewUpper(symbol) = Lower + D × CDFup to(symbol)
Intervals are scaled and shifted copies of the base [0,1) sub-intervals.
Tag = (Upper₍final₎ + Lower₍final₎) / 2
Any point inside the final interval works; here we use the midpoint.
